1. Information We Collect

Masum Smart Calculator Pro may collect or store the following information depending on how users use the app.

Account Information

When users use Google/Gmail login, the app may access:

  • Google account email address
  • Google account name
  • Google profile photo
  • Firebase user ID

This information is used only for login, backup, and restore features.

User-Entered Business Data

The app allows users to manually enter and save business or calculation records, including:

  • Customer or person name
  • Phone number
  • Address
  • Notes
  • Due amount
  • Paid amount
  • Receipt or memo details
  • Cashbook records
  • Saved calculations
  • Smart history records
  • Age, BMI, discount, profit/loss, EMI/loan calculation records

Backup Data

If users use cloud backup or restore, saved records may be stored securely in Firebase Cloud Firestore under the user's account.

Local Data

Some app data may be stored locally on the user's device, such as:

  • App settings
  • Theme preference
  • Saved records
  • PIN or app lock settings
  • Calculation history

2. How We Use Information

We use collected or stored information to:

  • Provide calculator and business notebook features
  • Save and show user records
  • Generate PDF reports
  • Share calculation or receipt details
  • Backup user data to Firebase
  • Restore user data after reinstall
  • Improve app functionality
  • Protect records with app lock or PIN features

We do not sell user data.

3. Data Sharing

Masum Smart Calculator Pro does not sell, rent, or trade user personal data.

Data may be processed by trusted third-party services used by the app, such as:

  • Firebase Authentication
  • Google Sign-In
  • Cloud Firestore

These services are used for login, backup, restore, and secure cloud storage.

When users manually share a PDF, receipt, memo, or calculation using WhatsApp, Messenger, email, or other apps, that sharing is controlled by the user.

4. Data Security

We take reasonable steps to protect user data.

  • Cloud data is stored using Firebase services.
  • User login is handled through Google/Firebase Authentication.
  • Data transmission uses secure Firebase/Google connections.
  • Local data stays on the user's device unless cloud backup is used.

However, no online or offline storage method is 100% secure. Users should keep their device, Gmail account, and app PIN safe.

5. Data Retention and Deletion

User data is kept as long as needed to provide app features.

Users can delete app data by:

  • Deleting saved records inside the app
  • Clearing app data from Android settings
  • Uninstalling the app
  • Requesting cloud data deletion by contacting the developer

For cloud backup data deletion, contact: farabi3577@gmail.com

Please include the Google login email used in the app so we can identify and delete cloud backup data.
